# Ядро 7. Визуализации в презентациях и документах

Когда запрос на презентацию, слайды, отчёт или документ включает данные, графики оформляются по тем же правилам, что и дашборды, с поправкой на носитель.

## Разделение ответственности

- **Механику файла** (слайды, шаблон, сохранение, формат) обеспечивает соответствующий навык: презентации, Word, PDF. Прочитай его правила первым.
- **Оформление графиков, чисел и таблиц** определяет этот набор правил и токены команды.
- При конфликте: честность данных и читаемость выше, чем шаблон презентации.

## Если нет навыка для нужного формата

Если среда не умеет создавать файл презентации (.pptx и аналоги), не имитируй его и не молчи. Отдай слайд как HTML 16:9 (один файл, токены, заголовок-вывод, заметки докладчика в блоке под слайдом) и скажи владельцу прямо: «Это HTML-слайд. Файл презентации создаст соответствующий навык или вы вставите график вручную». Отдельно сохрани график как SVG для вставки.

## Правила для слайдов

| Правило | Деталь |
|---|---|
| Один слайд = одно сообщение | Заголовок слайда = вывод (как заголовок графика) |
| График занимает не меньше ~60% площади слайда | Без декоративных рамок и фоновых картинок |
| Шрифты | Подписи не меньше 12pt, основные числа 18pt и выше |
| Формат | 16:9 (если шаблон команды не требует другого) |
| Прямые подписи | Легенды на слайдах не используются |
| Аннотация | Одна-две на слайд, чтобы направить внимание |
| Заметки докладчика | Источник, период, расчёты, как читать график |
| Цвет | Те же токены, что в дашборде. Одна категория = один цвет по всей презентации |
| Количество графиков | Максимум 2 на слайд. Если нужно сравнивать, используй small multiples на одном слайде |
| Таблицы | Только если нужны точные значения. Максимум 5 строк × 5 столбцов на слайде |

## Способ вставки графика (выбери по окружению и спроси владельца при первой настройке)

| Способ | Плюсы | Минусы |
|---|---|---|
| Нативный график презентации | Редактируется в самой программе | Сложно точно следовать токенам |
| Вектор (SVG) | Чёткий при любом масштабе | Не везде редактируется |
| Растр (PNG, 2×, 3×) | Работает везде | Не редактируется, размер файла |
| Встраивание HTML | Интерактив | Не везде поддерживается |

По умолчанию: нативный график, если нужна правка владельцем, иначе SVG или PNG@2×. Решение записывается в `presentation-rules.md`.

## Документы и отчёты

- Те же правила: заголовок-вывод, источник, примечание.
- Подпись под рисунком: «Рис. N. Вывод. Источник».
- Таблицы без вертикальных линий, числа справа, итоги отдельно.
- Алт-текст у каждого графика.

## Предсказуемость

Для каждого типа носителя в `presentation-rules.md` зафиксированы: размеры, шрифты, поля, способ вставки, образец. Без заданных значений агент не придумывает свои.
