# Ядро 2. Выбор графика: закрытый каталог простых форм

Цель: предсказуемый результат без сложных графиков. По умолчанию разрешены только формы из каталога. Сложные формы доступны только по явному одобрению владельца (раздел «Шлюз сложности»).

## Каталог (разрешено по умолчанию)

| Вопрос | Форма | Правила |
|---|---|---|
| Как меняется во времени? | **Линия** | Герой цветом, остальное серым, прямые подписи. До 4 линий |
| Как меняется в немногих периодах (≤ 6-8)? | **Вертикальные столбцы** | От нуля. Подписи значений сверху |
| Сколько у каждой категории? | **Горизонтальные столбцы** | Отсортированы, значения у концов, лидер цветом |
| Что изменилось между двумя моментами? | **Dumbbell** (две точки и линия) или **slopegraph** | Подписи слева и справа |
| Как связаны две переменные? | **Диаграмма рассеяния** | Подписаны выбросы и интересные точки. Линия тренда только если она нужна для вывода |
| Как распределены значения? | **Гистограмма** или **strip plot** | Подпись ширины интервала |
| Как устроено целое из ≤ 3 частей? | **Один столбец 100%** или просто числа | Больше 3 частей: горизонтальные столбцы |
| Сколько, и изменилось ли? | **KPI-карточка** | Значение, сравнение, спарклайн, дата |
| Много групп с одним показателем | **Small multiples** | Общая шкала |
| Нужны точные значения | **Таблица** | Столбцы по типам, выравнивание чисел вправо, мини-столбцы допустимы |
| Эта же история по регионам? | **Карта** только если важна география | Один тон, 5-7 классов, иначе столбцы |

## Правила выбора

1. Начни с вопроса, а не с графика: «что читатель должен понять или решить?»
2. Выбери простейшую форму из каталога, которая отвечает на вопрос.
3. Если подходит несколько, бери ту, где главное число кодируется позицией или длиной.
4. Если данных мало, лучше число или таблица, чем график.
5. Один график — один вывод. Второй вывод — второй график.

## Запрещено по умолчанию

pie, donut, 3D, radar, двойная ось, радужные градиенты, спидометры, воронки как фигуры, «объёмные» столбцы, карты тепла без подписей, диаграммы Венна с количественным смыслом.

## Шлюз сложности (для сложных форм)

Сложные формы: chord, Sankey, alluvial, сеть, дендрограмма, sunburst, treemap, parallel coordinates, радиальные и органические формы, анимированные потоки. Они допустимы только если выполнены **все** условия:

1. Владелец явно разрешил именно эту форму (записано в `house-style.md`).
2. Аудитория может прочитать её с ключом «Как читать».
3. Для той же истории есть простая альтернатива, и она приложена или доступна таблицей.
4. Форма добавляет смысл, а не только вид (ответь на вопрос: что видно здесь, чего не видно на столбцах?).
5. Лимиты соблюдены: до 20 групп, значения топ-связей подписаны, полная таблица доступна.

Если условие не выполнено, замени на простую форму и скажи об этом одной строкой.

## Расчёты, которые делаешь ты, а не пользователь

Проценты, изменения, индексы, доли, скользящие средние: считай кодом, а не «в уме». Покажи формулу в примечании, если расчёт нетривиален. Суммы проверяй на сходимость.
