# Правила визуализации данных: стиль редакционной дата-журналистики (в духе The New York Times / The Upshot)

Это описание приёмов, а не копия брендинга. Не использовать название, логотип, шапку или фирменные шрифты издания и не выдавать график за публикацию издания.

## 0. Как использовать этот файл

Файл прикрепляется к данным (CSV, XLSX, JSON, таблица в тексте). Claude обязан:

1. Прочитать данные и найти главный инсайт (один на фигуру).
2. Выбрать тип графика по разделу 5.
3. Выдать **один самодостаточный HTML-файл** (всё inline, без внешних стилей).
4. Применить все правила ниже. Если **стилевое** правило (цвет, шрифт, форма подписи, раскладка) конфликтует с запросом пользователя, приоритет у запроса: сообщи об этом одной строкой. **Правила честности данных запрос пользователя не отменяет:** столбцы от нуля, без двойных осей, 3D и круговых диаграмм, без подгонки вывода и скрытия данных. На такую просьбу объясни в одну-две фразы и сделай честную замену. Предупреждение не делает нечестный график допустимым, «оба варианта» не делай.
5. Прогнать чек-лист раздела 12 до выдачи.

Если инсайт неочевиден или историй несколько, выбери одну сам, назови её в ответе и спроси, нужна ли другая. Не задавай вопросов до первой версии.

Формат ответа после генерации: файл + 3-4 строки: какой инсайт и какая форма выбраны и почему, что в данных было нестандартного (пропуски, выбросы, агрегации).

### Когда использовать

Аналитическая статья, лонгрид, презентация для широкой аудитории, отчёт, который должен быть понятен без объяснений автора: тренды, сравнения, социальные исследования, карты, таймлайны, график с историей («здесь изменилось вот это, потому что…»).

Не использовать: данные без истории и без аномалий, которые стоит аннотировать (берите Yau), эмоционально-органичные темы (Fragapane), плотные сетевые связи (Bremer).

## 2. Принципы

1. **Сначала вывод.** Заголовок называет находку, график её доказывает.
2. **Серый по умолчанию.** Цвет появляется только там, где нужно привлечь внимание.
3. **Слой аннотаций — главный.** Объясни аномалии, переломы, диапазоны там, где они видны.
4. **Контекст.** Сравнение, эталон, предыдущий период: число без контекста ничего не значит.
5. **Без метафор.** Прямая форма (линия, столбец, точка, карта). Кто видит график, сразу понимает, что измерено.
6. **Статичность прежде всего.** История читается без интерактива, интерактив только для деталей.
7. **Прозрачный метод.** Источник, примечания и ограничения всегда указаны.

## 3. Токены

```css
:root {
  --bg: #F6F6F3;                  /* «газетный» бледно-серый. Белый вариант: #FFFFFF */
  --ink: #121212;
  --text-body: #333333;
  --text-muted: #666666;
  --gray-line: #B9B9B6;           /* контекстные серии */
  --grid: #E1E1DD;
  --axis: #999999;

  --tone-a: #2B6CA3;              /* герой / первая полярность */
  --tone-a-soft: #CFE0EE;
  --tone-b: #C23B2E;              /* вторая полярность, только когда данные полярны */

  --font-head: "Source Serif 4", Georgia, "Times New Roman", serif;   /* фирменные шрифты изданий не используем; файлы: ../fonts/README.md */
  --font-ui: "Source Sans 3", Arial, sans-serif;
}
```

**Правила цвета:**
- Серый для контекста, один цвет для героя. Остальное серое.
- 2-3 функциональных тона максимум. Два тона используются, только если данные **полярны** (до/после, больше/меньше, А/Б).
- Красный/синий: только партийные данные США. Для остальных контрастов: синий/оранжевый.
- Величина: один тон от светлого к тёмному. Отклонения от нуля: две полярности + нейтраль.
- Текст `--ink` и `--text-*`. Цветной текст только для подписи героя или полярного тона, с контрастом ≥ 4.5:1.

## 5. Типы графиков и контекст

| Задача | Форма |
|---|---|
| Изменение во времени | Линия, герой цветом, остальные серым |
| Сравнение категорий | Горизонтальные столбцы, отсортированы, значения у концов |
| Изменение между двумя точками | Dumbbell или slopegraph |
| Связь двух переменных | Scatterplot, подписаны выбросы и интересные точки |
| Много групп | Small multiples с общей шкалой |
| Распределение | Strip plot, гистограмма (распределение интереснее среднего) |
| Состав | Столбец-100% или область. Pie запрещён |
| Гео | Сдержанная подложка, 5-7 классов, один тон, отклонения двумя полярностями |

**Контекст (обязателен хотя бы один из):** эталонная линия (среднее, цель), прошлый период, сравнительная группа, затенённый диапазон («рецессия», «кампания»).

**Масштаб:** столбцы от нуля. Линия может не начинаться с нуля, но это отмечено. Логарифмическая шкала подписана.

## 6. Слой аннотаций (главное правило стиля)

- Минимум **одна**, обычно 2-5 аннотаций. Больше — шум.
- Аннотация = **два уровня**: жирный заголовок (что произошло) + пояснение (почему важно). Один абзац — не аннотация, перенеси в текст статьи.
- Привязка видна: кольцо на точке + тонкая выноска (1px, `--ink`). Выноска упирается **под** текст, не режет его.
- Текст стоит в пустом месте, поверх линий с обводкой `paint-order: stroke` цветом фона (4px).
- Без рамок, теней, подложек и стрелок «в стиле инфографики».
- Прямые подписи у концов линий вместо легенды. Герой выделен цветом и весом.
- Единицы повторяются на первой подписи сетки («60 ед.», «40%»).
- Подписи сетки сидят **над** линией внутри графика, а не в боковой колонке.
- Для необычного графика добавь пояснение «как читать» одной строкой («каждая точка — округ»).
- Не выдумывай причины. Аннотация объясняет только то, что есть в данных или названо пользователем.
- На узком экране (< 600px) аннотации превращаются в нумерованные маркеры на графике, а тексты идут списком под ним.

## 7. Заголовок и обвязка

- **Кикер:** рубрика, не бренд («Анализ», «Образование»).
- **Заголовок:** утверждение с числом, глагол обязателен («Рост ускорился после 2015 года, а доли остальных почти не изменились»). Без кликбейта. Без причинности, которой нет в данных.
- **Подзаголовок:** что измерено, где, период, единицы.
- **Подвал:** `Источник: …`, `Примечание: …`, при необходимости `Автор: …`. Линия сверху 1px `--grid`.

```
[Кикер]

```

Колонка 720px по центру, поля 20px, график на всю ширину колонки. Фон `--bg` без рамок и теней.

## 9. Честность

- Столбцы от нуля, площади через √, двойных осей нет.
- Сравнимые графики на одной шкале.
- Пропуски показаны разрывом, прогнозы пунктиром, оценки названы.
- Сглаживание и агрегации объявлены в примечании.
- Выбросы не подрезаются, их объясняют.
- Источник обязателен. Нет источника: «Источник: данные пользователя».

## 10. Технические требования

- Один HTML-файл, inline SVG на ванильном JS. D3 допустим только с `https://cdnjs.cloudflare.com/ajax/libs/d3/7.9.0/d3.min.js`.
- Данные константой в начале скрипта. Цвета и шрифты через CSS-переменные.
- `role="img"`, `<title>`, `<desc>`, контраст текста ≥ 4.5:1, информация не только цветом.
- 375px и 1280px. Минимальный шрифт 11px.
- Без localStorage, внешних запросов, счётчиков. Типографика текста: «ёлочки», ’, длинное тире.

## 12. Чек-лист

**Данные и контекст**
- [ ] Заголовок = вывод с числом, подзаголовок = что, где, когда, единицы.
- [ ] Есть контекст (эталон, период, сравнение).
- [ ] Столбцы от нуля, усечения отмечены.
- [ ] Источник и примечания есть.

**Аннотации**
- [ ] 1-5 аннотаций, два уровня текста, выноска под текстом.
- [ ] Легенды нет, подписи у концов линий, единицы на первой подписи.
- [ ] Причины не выдуманы.

**Дизайн**
- [ ] Серый контекст, цвет только у героя.
- [ ] ≤ 3 функциональных тона, красный/синий только для партий.
- [ ] Серифный заголовок, sans для подписей, нет фирменных шрифтов издания.
- [ ] Нет рамок, теней, 3D, декора.

## 13. Антипаттерны

- Заголовок-тема («Динамика показателей»).
- Лес аннотаций: 10 подписей на графике.
- Аннотации-абзацы.
- Легенда в углу, радужная палитра, больше 3 тонов.
- Красный/синий для не-партийных данных.
- Копирование логотипа, шапки или шрифтов издания.
- Серый фон как «признак NYT»: стилизация, не стандарт.
- Усечённая ось у столбцов.
- Интерактив, без которого история не читается.
