# Шрифты для пяти стилей

Файлы в этой папке — переменные TTF из репозитория Google Fonts; для каждого сохранён оригинальный текст SIL Open Font License 1.1. Источники и метаданные:

- Source Sans 3 — `SourceSans3.ttf`, `sourcesans3-OFL.txt`, https://github.com/google/fonts/tree/main/ofl/sourcesans3
- Source Serif 4 — `SourceSerif4.ttf`, `sourceserif4-OFL.txt`, https://github.com/google/fonts/tree/main/ofl/sourceserif4
- Manrope — `Manrope.ttf`, `manrope-OFL.txt`, https://github.com/google/fonts/tree/main/ofl/manrope
- Literata — `Literata.ttf`, `literata-OFL.txt`, https://github.com/google/fonts/tree/main/ofl/literata

У всех четырёх заявлены наборы Latin и Cyrillic. Проверяй фактические символы используемого языка: наличие кириллицы не означает поддержку всех языков с кириллической письменностью. Текст лицензии копируется рядом с каждым распространяемым файлом шрифта.

## Выбор по умолчанию

| Стиль | Заголовки | Текст, подписи, данные | Системные запасные |
|---|---|---|---|
| Yau | Source Sans 3 | Source Sans 3 | Arial, sans-serif |
| NYT / редакционный | Source Serif 4 | Source Sans 3 | Georgia, serif / Arial, sans-serif |
| Fragapane | Literata | Manrope | Georgia, serif / Arial, sans-serif |

Это наши открытые рекомендации по роли и читаемости, не утверждение, что названные авторы используют эти семейства.

## Алгоритм

1. Если владелец дал брендовые шрифты, они имеют приоритет при наличии лицензии, поддержки текста и доступности в целевом формате. Не выдавай неподтверждённое за факт: если сведения отсутствуют, зафиксируй TBD и выбери семейство из таблицы для недоступной роли.
2. Иначе автоматически выбери пару по основному стилю. Для вторичного стиля сохрани отдельные токены и применяй их только когда выбран этот стиль; категории, значения и данные этим не меняются. Не спрашивай владельца о каждом шрифте: покажи выбранное в итоговой сводке, дай возможность заменить.
3. Скопируй нужные `.ttf` и соответствующие `*-OFL.txt` в `assets/fonts/` создаваемого скилла. В `assets/tokens.css` объяви `@font-face` с относительным `url('fonts/имя.ttf')`, `font-style: normal`, `font-weight` по диапазону ниже и `font-display: swap`. Задай `--font-display`, `--font-body`; оставь `--font: var(--font-body)` для старых скелетов. Сохрани список ролей, источник и лицензию в `references/brand-tokens.md`. Если шаблон не позволяет заменить `font-family`, согласуй скелет с токенами.
4. Вес: Source Sans 3 и Source Serif 4 — 200 900; Manrope — 200 800; Literata — 200 900. Файлы содержат только обычное начертание: не утверждай, что настоящий курсив включён. Для курсива подключай отдельный лицензированный файл либо используй обычное начертание.
5. Для переносимого HTML рядом с CSS разрешены относительные файлы; для единого автономного HTML встраивай шрифт при возможности с соблюдением лицензии и ограничений размера или явно используй системный запасной стек. Не подключай сторонние шрифты с сети без необходимости или разрешения: по одному имени шрифт на другом компьютере не гарантирован. В чатовой сборке файлов шрифтов нет — сообщи об этом и используй запасные стеки до получения файлов.
6. В PPTX и документах укажи фактически используемое семейство; если файл шрифта нельзя встроить или установить, используй запасной шрифт и отметь возможную смену переносов строк. Проверь визуально на целевом устройстве. Табличные цифры: `font-variant-numeric: tabular-nums` где поддерживается.

Минимальная проверка: открой файл шрифта, проверь кириллические и латинские буквы, цифры и знаки из конкретного материала; проверь пути файлов, корректность @font-face, список токенов и отображение в целевой среде. Валидатор структуры сам по себе не подтверждает, что шрифт загружен.
