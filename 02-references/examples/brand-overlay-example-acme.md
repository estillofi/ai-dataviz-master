# Пример: как базовый стиль адаптируется под бренд (вымышленная команда Acme)

Показывает метод. Значения вымышлены. Структура и порядок шагов настоящие.

Бренд Acme: синий `#2457C5` (основной), оранжевый `#F28C28` (акцентный), тёмно-синий текст `#1B2A41`, фон страниц `#F7F8FA`, шрифт Inter.

## Шаг 1. Разделить цвет бренда и цвет данных

Цвет логотипа нужен для узнаваемости. Цвет данных нужен, чтобы его было видно и различимо. Это разные задачи.

| Роль | Цвет бренда | Для данных | Что случилось |
|---|---|---|---|
| Основной | `#2457C5` | `#2457C5` | Контраст 6.09:1 к фону, менять не нужно |
| Акцентный | `#F28C28` | `#C2620A` | Бренд-оранжевый даёт 2.31:1 (нужно ≥ 3:1 для графики). Взят тот же тон, темнее: 3.92:1 |
| Оранжевый в мелком тексте | `#F28C28` | `#B34D00` | Для текста нужно ≥ 4.5:1, получилось 4.97:1 |
| Контекстные данные (серые) | нет | `#7B8794` | Прежний `#9AA5B1` давал 2.36:1, поэтому светлее не нужно |

Правило: бренд-оранжевый остаётся в логотипе и крупных декоративных элементах. В данных его производная.

## Шаг 2. Токены (Yau + Acme)

```css
:root {
  --bg: #F7F8FA;  --ink: #1B2A41;  --text-body: #3A4A63;  --text-muted: #566277;
  --grid: #E4E7EB;  --axis: #9AA5B1;
  --data-base: #7B8794;  --data-base-light: #CBD2D9;
  --accent: #C2620A;  --accent-text: #B34D00;
  --font: "Inter", -apple-system, "Segoe UI", Arial, sans-serif;
}
```

У Yau остаётся ровно **один акцент**. Синий бренда в данных не используется как второй цветной: он в заголовках и подписях интерфейса.

## Шаг 3. Токены (NYT + Acme)

```css
:root {
  --bg: #F7F8FA;  --ink: #1B2A41;  --gray-line: #B9C0C9;  --grid: #D9DEE4;
  --tone-a: #2457C5;  --tone-a-soft: #D4DEF3;
  --tone-b: #C2620A;
  --font-head: Georgia, "Times New Roman", serif;
  --font-ui: "Inter", -apple-system, "Segoe UI", Arial, sans-serif;
}
```

## Шаг 4. Компромиссы (записываются в `house-style.md`)

| Что у автора стиля | Что у нас | Почему |
|---|---|---|
| Акцент красный (Yau) | Акцент оранжевый производный | Цвет бренда, прошёл контраст |
| Белый фон (Yau) | Очень светлый серо-голубой | Фон бренда |
| Серифный заголовок (NYT) | Сохранён | Определяет жанр. Бренд-шрифт только для подписей |
| Две полярности красный/синий (NYT) | Синий/оранжевый | Нет партийной семантики |

## Шаг 5. Аудит

`python3 tools/palette_audit.py --bg "#F7F8FA" --text "#1B2A41" "#566277" "#B34D00" --graphics "#2457C5" "#C2620A" "#7B8794" --categorical "#2457C5" "#C2620A" "#1B8A6B" "#8E5BB5" "#566277"`

Первая версия палитры содержала шесть категорий и дала 3 предупреждения: розовый `#C0397B` сливался с серым при протаномалии и с зелёным при дейтераномалии. Шестой цвет убран, предупреждений 0.

## Что запомнить

1. Бренд не меняется молча: каждая пара «бренд → для данных» показывается владельцу.
2. Структура стиля сохраняется: один акцент (Yau), слой аннотаций (NYT), ключ «Как читать» (Fragapane, Bremer, Lupi).
3. Все отклонения записаны с причиной.
4. Проверка делается инструментом, а не на глаз.
