# Примеры

| Что | Зачем |
|---|---|
| `brand-overlay-example-acme.md` | Как базовый стиль адаптируется под бренд: разделение «цвет бренда / цвет данных», токены, компромиссы, аудит. Вымышленная команда Acme |
| `acme-dataviz/` | **Полный пример результата сборки:** валидный скилл с описанием-триггером, токенами, решениями команды, каталогом, правилами для дашбордов и презентаций, глоссарием, тестами, ядром и стилем Yau, эталонным дашбордом в `examples/`. Проверяется `python3 tools/validate_skill.py 02-references/examples/acme-dataviz` |

Палитра Acme показывает цикл аудита: первая версия с шестью категориями дала три предупреждения, после правки их ноль.
Тесты скилла в примере не прогонялись: это образец структуры.
