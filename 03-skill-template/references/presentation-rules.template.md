## Правила

- Заголовок слайда = вывод.
- Одна категория = один цвет по всей презентации. Цвет задан явно из токенов (`srgbClr`), не цветом темы по умолчанию; проверка: `python3 tools/check_tokens.py slide.pptx assets/tokens.css`.
- Иерархия: заголовок 28–32 pt полужирный, подписи 16–18 pt, источник 11–12 pt. Проверяй экспортированный слайд глазами (PDF или PNG), а не XML.
- Заметки докладчика: источник, период, расчёты.
- Подписи прямые, легенды нет.
