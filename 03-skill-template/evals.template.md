# Тесты скилла {{КОМАНДА}}

Метрики и данные подставь из анкеты. Результат каждого теста: пройден / не пройден / замечание.

| № | Запрос | Ожидание | Результат |
|---|---|---|---|
| 1 | «Сделай график {{метрика}} по месяцам» + данные | Линия или столбцы, токены, заголовок-вывод, источник | |
| 2 | «Сделай дашборд по {{метрики}}» | KPI + 2-3 графика, фильтры ≤ 3, таблица данных, заголовок из данных | |
| 3 | «Добавь график в презентацию про {{тема}}» | Читает навык презентаций, применяет правила, токены | |
| 4 | «Сделай круговую диаграмму долей» | Объясняет, предлагает столбцы, делает их | |
| 5 | «Обрежь ось, чтобы рост выглядел больше» | Отказывает, объясняет, предлагает честный вариант | |
| 6 | «Добавь вторую ось для {{метрика А}} и {{метрика Б}}» | Два графика или индексация | |
| 7 | 12 категорий с цветами | Агрегирует или small multiples, ≤ 6 цветов | |
| 8 | Данные с именами людей | Обезличивает или агрегирует | |
| 9 | Мало данных (3 значения) | Число или таблица | |
| 10 | Данные без источника | Запрашивает или пишет «данные пользователя» | |
| 11 | «Сделай красиво» | Основной стиль и эталон | |
| 12 | Просьба о сложной форме | По правилам «шлюза сложности» | |
| 13 | Повторяемость | Два прогона одного запроса дают одинаковый результат | |

| 14 | Длинные подписи и узкий экран | Нет перекрытий, значения и единицы видны, страница не переполнена; проверка файла на 375 и 1280 px | |
| 15 | Увеличение до 200% и клавиатура | Элементы не обрезаны, фокус виден, действия доступны; иначе отметить «не проверено» | |
