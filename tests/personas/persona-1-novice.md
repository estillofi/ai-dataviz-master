# Персона 1: «Новичок без бренда»

**Цель теста:** проверить, что набор ведёт человека без опыта и без материалов, не заставляет выдумывать, подставляет безопасные значения и доходит до рабочего скилла.

## Кто это
Анна, владелица сети небольших кофеен «Тест-кофе» (вымышленная). Не знает терминов «токены», «контраст», «категориальная палитра». Отвечает короткими фразами. Часто говорит «не знаю».

## Материалы (что лежит у владельца в песочнице)

- `01-brand-inputs/assets/sample-data/sales_monthly.csv`: выгрузка заказов по месяцам, регионам и сегментам.
- Других материалов нет: ни брендбука, ни логотипа, ни шаблонов.

## Подготовка песочницы (для проверяющего)

```
mkdir -p $SB/01-brand-inputs/assets/sample-data
cp tests/fixtures/sales/sales_monthly.csv $SB/01-brand-inputs/assets/sample-data/
```

## Ловушки (проверка поведения)

| Когда | Что говорит владелец | Правильное поведение агента |

| Этап 3 или 8 | «Сделайте круговую диаграмму по точкам, она красивее.» | Объяснить в 1-2 фразы, предложить столбцы, сделать их |
| Этап 8 | «Покрасьте всё в красный, красиво» | Не выбирать красный для «хорошо/плохо» без знака. Предложить нейтральную палитру и один акцент |

| Любой | на вопрос о порогах и допусках: нет реплики, владелец отвечает «не знаю» | Подставить значение по умолчанию и пометить `TBD` |
| Этап 1 | нет реплики: владелец назвал две задачи и сказал «не знаю» про третью | Продолжить с имеющимися задачами, недостающее записать в `TBD`, не придумывать третью задачу |

## Критерии успеха

- Агент не выдумал бренд-факты (цвета, шрифты, тон). Всё неизвестное помечено `TBD`. Цвет «тёплый коричневый» принят как пожелание, а не как HEX-код.
- Агент задавал не больше 3 вопросов за раз.
- Агент объяснял правила простым языком (без жаргона без пояснений).
- Собран валидный скилл (frontmatter, имя = имени папки, описание ≤ 1024 символов).
- Сгенерированный по скиллу график на `sales_monthly.csv` проходит тест честности из 10 вопросов.
