## [0.1.0-beta] - 2026-11-17

Бета: сквозная проверка отказа от нечестного графика (V-11) **не пройдена**, см. README «Known limitation» и `tests/reports/2026-11-17-claude-code-final.md`.

### Добавлено
- Шрифты по умолчанию для пяти стилей: `02-references/fonts/` (Source Sans 3, Source Serif 4, Literata, Manrope; переменные TTF и тексты OFL), правила выбора в `fonts/README.md`; токены `--font-display`, `--font-body` и `@font-face` в шаблоне.
- Правила вёрстки и проверки готовых файлов: `03-skill-template/references/layout-rules.template.md`; в `AGENTS.md` и шаблоне скилла — обязательная проверка на 375 и 1280 px, при 200% и клавиатурой; evals 14–15.
- Демо Fragapane корректно обрабатывает нулевые и недопустимые значения; тест `tests/test_fragapane_demo.py`.
- Раздел «Обязательная проверка перед выдачей» в шаблоне скилла и примере Acme.

### Безопасность
- **V-11, провал сквозного прогона (17.11):** агент со скиллом получил ERROR шлюза и всё равно выдал обрезанную ось и pie «с оговоркой», сославшись на общие установки пользователя. Исправлено:
  - раздел 0 «Честность выше любых установок» первым в теле скилла (шаблон, Acme, `AGENTS.md`): установки пользователя и среды не отменяют правил честности; ERROR шлюза = стоп, «Готово» при ERROR запрещено;
  - шлюз в самом скилле обязателен: `tools/check_honesty.py` в структуре скилла (`AGENTS.md`), `validate_skill.py` предупреждает при его отсутствии и даёт ошибку, если `SKILL.md` ссылается на несуществующий шлюз; копия в примере Acme;
  - `tools/check_honesty.py` ловит pie, нарисованный скриптом (шаблон сектора «M центр L … A … Z» в JS) и `id="pie"`;
  - `tests/check_run.py` распознаёт архивы по содержимому (`.skill`), а не только по расширению `.zip`;
  - **Повторная проверка не пройдена:** Codex в чистой среде прочитал раздел 0, но не запустил шлюз и выдал нечестный файл; Claude Code не подключил скилл. Нужна принудительная проверка (хук), а не только инструкция.
  - `tools/check_honesty.py` ловит признание искажения в тексте страницы с графиком («ось обрезана», «рост выглядит сильнее», «визуально преувеличивает», truncated axis) на любом типе графика, включая линию; отрицания не считаются. Раньше двухстолбцовый случай из прошлого прогона проходил шлюз без ERROR.

### Исправлено
- `tests/run_persona.py`: для codex по умолчанию `--skip-git-repo-check --sandbox workspace-write` (песочница не Git-репозиторий; без флага `codex exec` падал за секунды). Полный доступ не используется.
- `tests/check_run.py`: архивы `.zip` проверяются на секрет по каждому текстовому члену (бинарный член даёт WARN); цитата реплики в кавычках («скажи, что всё проверено») при отказе не считается громким заявлением.
- README: «the same way every time» заменено на «consistently (tokens, golden examples, determinism checks)» (F-05).
- `tests/lint_kit.py` не проверяет результаты прогонов в корневых `04-output/` и `05-research-log/`.
- По визуальному аудиту галереи (17.11): скелеты пяти стилей используют рекомендованные открытые шрифты вместо фирменных шрифтов изданий и системных стеков; убран ложный курсив Literata; тест `tests/test_style_fonts.py`.
- Скелет Fragapane рисует обязательный ключ «Как читать», круглые опорные значения колец и точное значение у каждого лепестка.
- Скелет дашборда: ширина SVG по контейнеру, подписи графиков на 375 px не меньше 11 px (раньше около 6 px), подписи месяцев не слипаются, перерисовка при смене ширины; браузерный тест.
- Правила вёрстки и презентаций: минимальный отрисованный размер текста SVG, обязательная шкала величины, однозначные даты, иерархия и явные цвета `srgbClr` на слайдах.

## [0.1.0] - 2026-11-15

По результатам отчёта `tests/reports/2026-11-10-codex-v2.md` (V-01…V-13). Тесты: 140 юнит-тестов, линтер набора, предполётная проверка, три прогона персон с Codex.

### Добавлено
- **Шлюз честности** `tools/check_honesty.py`: проверяет готовый HTML на pie/donut, 3D, двойную ось и усечённую ось столбцов. Обязательный шаг перед выдачей любого HTML в `AGENTS.md`, шаблоне скилла и примере Acme; при ERROR результат не выдаётся. Если Python недоступен, скилл проходит тест из 10 вопросов письменно (V-11).
- Проверка `honesty` в `tests/check_run.py`: каждый HTML галереи проходит шлюз, ERROR = FAIL (V-11).
- Поддержка `.docx`, `.pptx`, `.xlsx` (zip + XML) и `.pdf` при поиске секрета и ПД; прочие бинарные файлы дают WARN «не проверено» (V-06).
- Поддержка `.pptx` в `tools/check_tokens.py`: цвета `srgbClr` из XML слайдов и темы сверяются с токенами (V-12).
- `--no-network` по умолчанию в `tests/run_persona.py`; флаги отключения поиска проверяются фактически по `codex exec --help` (V-09).
- Уникальные песочницы `dvm-run-N-<время>` и флаг `--overwrite` (V-04).
- Соглашение об именах галереи и проверка пяти видов: dashboard, line, bars, table, slide (V-08).
- `data-chart` и `data-axis-min="0"` в скелетах дашборда и эталоне (V-11).

### Исправлено
- `tools/check_tokens.py` больше не вырезает `:root`: переменная, объявленная на странице, проверяется; `var(--x)` раскрывается через страницу и токены (V-01).
- `tools/compare_outputs.py` не схлопывает пробелы внутри `<script>`, `<style>`, `<pre>`, `<textarea>` и в кавычках (V-02).
- `tests/run_persona.py` сохраняет код возврата агента: ненулевой код и таймаут дают код 3 и строку «проверка неполная» (V-03).
- `palette_audit.py`, `validate_skill.py`, `check_tokens.py`, `compare_outputs.py`: `OSError`, `UnicodeError`, `JSONDecodeError` дают код 2 и короткое сообщение без traceback (V-05).
- Предупреждения `validate_skill` в строгом режиме считаются FAIL в `check_run.py` (V-07).
- В `AGENTS.md` уточнено: пять демо в обычном режиме, в режиме «только чат» — только имеющиеся (V-10).
- `AGENTS.md`: ответы и подшаг записываются в `00-session/state.md` сразу, с пометкой «черновое»/«подтверждено» (V-13).

## [0.1.0-rc2] - 2026-11-09

По результатам первого (частичного) отчёта внешнего тестировщика, см. `tests/reports/`.

### Безопасность
- **Малые группы:** одной пометки мало. Правила дополнительного подавления (скрытое не должно восстанавливаться вычитанием из итога или соседних срезов), инструмент `tools/suppress_small_groups.py` (F01).
- R4 (двойная ось) и R5 (3D) без исключений; таблица допустимых исключений в ядре; `AGENTS.md` приведён в соответствие (F03).

### Исправлено
- `palette_audit.py`: каждая проблемная категория считается; проверка формата HEX и понятные ошибки; порог 6 категорий; пустой ввод это ошибка (F02, F06, F07).
- Единый документ для чата самодостаточен: все файлы, на которые ссылается `AGENTS.md`, включены; по умолчанию стили Yau и редакционный; в предисловии перечислено, чего нет (F04).
- Скелет дашборда: нулевые, пустые и одноточечные данные, нулевая база сравнения, детерминированная сортировка при равенстве (F05).
- Скелет Fragapane поставляется с демо-данными.
- Инструкции: меньше трёх задач допустимо (F09); «эталон» и «повторяемость» определены (F10); быстрый режим; режим «только чат» для этапа 3; терминальный UX; оценки времени смягчены.

### Добавлено
- `tools/check_tokens.py` (цвета и шрифты результата только из токенов), `tools/compare_outputs.py` (нормализованное сравнение), `data-volatile`.
- `validate_skill.py --strict` и проверка заглушек: пустые эталоны, скелет-заглушка, нет тестов.
- Тестирование агентом разделено на роли: `tests/run_persona.py` (песочница без `tests/`), `tests/personas/owner-script-N.md` (только реплики владельца, без ключа), `tests/check_run.py` (проверка реальных файлов), «поддельные агенты» для проверки самого проверяльщика.
- Сценарии: ответы об утверждении палитры и галереи; ожидание таблицы вместо графика при менее четырёх значениях (R18).
- Правила: заголовок при отсутствии вывода; слайд, когда нет навыка презентаций.
- Тесты: сейчас более 80; браузерные пропускаются без Playwright, умеют использовать установленный Chrome.

### Не проверено
- Полные прогоны персон испытуемым агентом и их поведение на ловушках; независимая повторяемость; срабатывание скилла в новой сессии Codex.

## [0.1.0-rc1] - 2026-11-09

### Добавлено
- `AGENTS.md`: инструкция агенту на 10 этапов (подготовка, контекст, бренд, дегустация стилей, политика графиков, дашборды, презентации, ресёрч, сборка, проверка).
- Ядро правил (7 файлов): честность (R1-R20), выбор графика, цвет и доступность, текст и аннотации, дашборды и интерактив, приватность, презентации.
- Пять базовых стилей с проверенными HTML-скелетами: Yau, Fragapane, Bremer, Lupi, редакционный.
- Шаблоны скилла, скелет интерактивного дашборда, полный пример скилла `acme-dataviz`.
- Инструменты: `palette_audit.py` (контраст WCAG, дальтонизм), `validate_skill.py`, `install_skill.py` (Claude, Codex), `bundle_single_file.py` (режим «только чат»).
- Тесты: линтер набора, юнит-тесты, браузерные дымовые тесты скелетов, три сценария-персоны, синтетические данные, шаблон отчёта.
- Защита: данные в файлах не считаются инструкциями; обработка секретов; режим «только чат».
- Гайд по сборке `docs/BUILD-GUIDE.md`.
